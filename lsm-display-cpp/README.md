# شاشة عرض أسهم سوق المال الليبي — نسخة C++ / Qt

تطبيق مكتبي أصلي (Native) لشاشة عرض الأسهم، مطابق في تصميمه لنسخة الويب وبهوية السوق (كحلي/ذهبي)، مخصص للتشغيل الدائم على جهاز شاشة القاعة أو البهو دون الحاجة إلى متصفح أو اتصال بالإنترنت.

## المكوّنات

| الملف | الوظيفة |
|---|---|
| `main.cpp` | نقطة التشغيل — خيارات سطر الأوامر، الاتجاه RTL، واختيار الخط العربي المتاح |
| `MarketData.h / .cpp` | نموذج البيانات، قراءة `data/session.json`، الإجماليات والقطاعات، وفحص سلامة البيانات |
| `data/companies.json` | الملف المرجعي للشركات: الاسم، القطاع، **عدد الأسهم المصدرة** |
| `tools/lsm_feeder.py` | منظومة التغذية: تحويل تقرير التداول (Excel/CSV) إلى `session.json` آليًا |
| `tests/` | اختبارات آلية لنموذج البيانات (QtTest) ولمنظومة التغذية (unittest) |
| `DisplayWindow.h / .cpp` | الواجهة الموحّدة في شاشة واحدة: الشريط المتحرك، المؤشر، الإحصاءات، جدول الأسعار، الأكثر تداولًا، خريطة السوق والقطاعات |
| `data/session.json` | بيانات الجلسة (أرقام استرشادية — تُستبدل بأرقام التقرير اليومي) |
| `CMakeLists.txt` | ملف البناء — يدعم Qt 6 و Qt 5 |

## الترجمة على ويندوز (جهاز شاشة العرض)

1. تثبيت **Qt** من الموقع الرسمي (Qt Online Installer) — تُختار حزمة `Qt 6.x — MSVC` أو `MinGW` مع **Qt Creator**.
2. فتح `CMakeLists.txt` من داخل Qt Creator (File ← Open File or Project).
3. اختيار العدّة (Kit) ثم الضغط **Build ← Run**.
4. للتوزيع على أجهزة أخرى: من مجلد البناء يُنفَّذ
   ```
   windeployqt lsm-market-display.exe
   ```
   فينسخ مكتبات Qt المطلوبة بجوار الملف التنفيذي، ويُنقل المجلد كاملًا (مع مجلد `data`) إلى جهاز الشاشة.

## الترجمة على لينكس

```bash
sudo apt install qt6-base-dev cmake g++
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
cmake --build . -j4
ctest --output-on-failure     # تشغيل الاختبارات
./lsm-market-display
```

## التشغيل والتحكم

| المفتاح | الوظيفة |
|---|---|
| **F11** | ملء الشاشة (عرض القاعة) |
| **Esc** | الخروج من ملء الشاشة |
| **R** أو **F5** (أو «ق» بلوحة المفاتيح العربية) | إعادة تحميل البيانات فورًا |

### خيارات سطر الأوامر

| الخيار | الوظيفة |
|---|---|
| `-f`, `--fullscreen` | البدء مباشرة في وضع القاعة (ملء الشاشة + إخفاء مؤشر الفأرة) |
| `-d`, `--data <file>` | مسار ملف البيانات (مثلاً مجلد مشترك على الشبكة) |
| `--scale <x>` | تكبير الواجهة لشاشات القاعة الكبيرة، مثلاً `1.5` لشاشة 4K |
| `--poll <sec>` | فترة فحص تعديل الملف (افتراضي 5 ثوانٍ) |
| `--stale <min>` | دقائق بلا تحديث أثناء الجلسة قبل ظهور تنبيه «بانتظار التحديث» (افتراضي 10) |
| `--page <sec>` | فترة التمرير الآلي للجدول إذا زادت الشركات عن مساحة الشاشة (افتراضي 8) |
| `--snapshot <png>` | حفظ صورة للشاشة ثم الخروج — للنشر على الموقع/وسائل التواصل أو للتحقق |

مثال اختصار التشغيل التلقائي على جهاز القاعة:

```
lsm-market-display.exe --fullscreen --scale 1.25
```

جميع اللوحات معروضة معًا في شاشة واحدة: الشريط المتحرك، المؤشر والإحصاءات، جدول الأسعار (الوسط)، الأكثر ارتفاعًا/انخفاضًا/نشاطًا (جانبًا)، وخريطة السوق والقطاعات (أسفل الشاشة) — دون تنقّل بين لوحات.

## ربط البيانات (منظومة التغذية)

```
تقرير التداول (Excel/CSV)  ──►  tools/lsm_feeder.py  ──►  data/session.json  ──►  الشاشة
                                      ▲
                     data/companies.json (الاسم، القطاع، عدد الأسهم)
```

**تحويل تقرير واحد:**

```bash
python tools/lsm_feeder.py report.xlsx --index 1134.57 --index-prev 1139.04
```

**التشغيل الدائم أثناء الجلسة** — يراقب مجلدًا ويحوّل أحدث تقرير يُحفظ فيه:

```bash
python tools/lsm_feeder.py --watch "D:\LSM\reports" --interval 30
```

ما يقوم به آليًا:

- يتعرف على أعمدة التقرير بأسمائها العربية أو الإنجليزية («رمز السهم»، «سعر الإغلاق»، «الكمية المتداولة»، «Close»، «Volume»…)، ويبحث عن سطر العناوين في أول 30 سطرًا، ويتجاهل سطور الإجمالي. يقبل الأرقام العربية (١٢٣) والفواصل، وملفات CSV بترميز ويندوز العربي.
- يضيف كل الشركات المدرجة من `companies.json` حتى غير المتداولة، ويرحّل سعر الإغلاق السابق تلقائيًا من آخر جلسة إذا غاب من التقرير.
- يبني مسار المؤشر خلال الجلسة (كل قيمة جديدة تُضاف للرسم البياني).
- يطبع تحذيرات الفحص (سعر خارج النطاق، تغير يتجاوز 10%، شركة بلا عدد أسهم…).
- يكتب الملف كتابة ذرّية، فلا تقرأ الشاشة ملفًا ناقصًا.

يحتاج بايثون 3.8+ فقط، ومكتبة `openpyxl` لملفات Excel (`pip install openpyxl`). لإضافة اسم عمود جديد يكفي إضافته إلى `COLUMN_ALIASES` في أعلى الملف.

اختبارات منظومة التغذية: `python -m unittest discover -s tests -p "test_feeder.py"`

## القيمة السوقية

تُحسب القيمة السوقية لكل شركة = **عدد الأسهم المصدرة × آخر سعر**. يُعبّأ عدد الأسهم في `data/companies.json` (حقل `shares`)، أو عمود «عدد الأسهم المصدرة» في التقرير، أو حقل `shares` في `session.json`. وتلتقط الشاشة أي تعديل على `companies.json` تلقائيًا.

ما يظهر على الشاشة:

- **بطاقة القيمة السوقية للسوق** (بالمليون دينار) مع تغيرها اليومي و**معدل الدوران** (قيمة التداول ÷ القيمة السوقية). وإذا كانت الأعداد ناقصة يظهر بيان التغطية (مثلاً `7/11 شركة`) حتى لا يُفهم الرقم على أنه إجمالي السوق.
- **عمود «ق.سوقية (م)»** في جدول الأسعار.
- **أداء القطاع مرجّحًا بالقيمة السوقية** متى عُرف عدد أسهم كل شركات القطاع، مع حصة القطاع من السوق. وما دامت الأعداد ناقصة يُحسب بأوزان متساوية ويُعلَّم بنجمة `*`.

> عدد الأسهم في `companies.json` متروك فارغًا (`null`) عمدًا، ويجب تعبئته من سجلات الإيداع والقيد المركزي. أما الأرقام في البيانات الاسترشادية المدمجة فهي للعرض فقط.

## تحديث البيانات

يقرأ التطبيق ملف `data/session.json` بجوار الملف التنفيذي، **ويفحصه كل 5 ثوانٍ ويعيد قراءته فقط عند تغيّره**، فيكفي أن تكتب منظومة التغذية (`feeder.py` في حزمة lsm-platform) أو الموظف المختص الأرقام الجديدة فوق الملف لتظهر على الشاشة مباشرة دون إعادة تشغيل.

حقول الملف:

```json
{
  "demo": false,
  "session": { "date": "2026-11-02", "openT": "10:00", "closeT": "13:00", "status": "auto" },
  "index":   { "value": 1850.10, "prev": 1847.62, "series": [1847.62, 1848.3, 1850.10] },
  "stocks":  [ { "sym": "BTD", "name": "مصرف التجارة والتنمية", "sector": "المصارف",
                 "prev": 12.650, "open": 12.700, "high": 12.800, "low": 12.650, "last": 12.750,
                 "vol": 120000, "val": 1526400, "trades": 80, "shares": 150000000 } ]
}
```

- `status`: `auto` (حسب مواعيد الجلسة الأحد–الخميس) أو `open` أو `closed`.
- `demo`: عند جعلها `false` تختفي عبارة «بيانات استرشادية».
- تُقبل الأرقام كأرقام أو كنصوص (`"1,250.5"`)، وإذا غاب `last` يُعتبر مساويًا لـ `prev`.
- **يُنصح بالكتابة الذرّية** من منظومة التغذية: الكتابة إلى `session.json.tmp` ثم إعادة التسمية فوق `session.json`. وإن قُرئ ملف ناقص أثناء الكتابة تبقى آخر بيانات سليمة معروضة ويُعاد المحاولة تلقائيًا.

## منطق الحسابات

- التغير والتغير٪ والإجماليات تُحسب داخل التطبيق من الأرقام المدخلة.
- **الاتساع (صاعد/مستقر/هابط)** يُحسب على الشركات المتداولة فقط؛ وبطاقة «الشركات المتداولة / المدرجة» تُظهر الرقمين معًا.
- **أداء القطاع** = تغير القيمة السوقية للقطاع (مرجّح بالقيمة السوقية) عند توفر عدد الأسهم لكل شركاته، وإلا متوسط التغير٪ بأوزان متساوية (معلَّم بـ `*`).
- «الأكثر ارتفاعًا/انخفاضًا» تعرض فقط الأسهم التي تغيّر سعرها فعلًا، و«الأكثر نشاطًا» فقط ما له قيمة تداول.
- الأسهم غير المتداولة تظهر باهتة، وتُعرض خانات الافتتاح/الأعلى/الأدنى/الكمية بعلامة «—» بدل 0.
- خريطة السوق ملوّنة بتدرّج أخضر/أحمر بحسب نسبة التغير (مُقيَّدة عند ±5%)، وعرض البلاطة بحسب قيمة التداول.
- الترتيب ثابت (القيمة ثم الرمز) فلا تتبدل الصفوف بين التحديثات.

## الرقابة على البيانات

- **فحص سلامة تلقائي** بعد كل تحميل: رمز مكرر، أسعار صفرية/سالبة، الأعلى أقل من الأدنى، آخر سعر خارج نطاق التداول، متوسط التنفيذ (القيمة ÷ الكمية) خارج النطاق، كمية بلا قيمة أو بلا صفقات. تظهر التحذيرات للمشغّل في سطر الملاحظة (وفي سجل الخطأ القياسي)، **ولا تظهر للجمهور في وضع القاعة**.
- تنبيه «الأرقام لجلسة سابقة» إذا كان تاريخ الملف غير تاريخ اليوم.
- مؤشر الحالة يتحول إلى «الجلسة جارية — بانتظار التحديث» (برتقالي) إذا لم يتغير الملف خلال الجلسة أكثر من المدة المحددة.
- عرض «آخر تحديث» بتوقيت تعديل الملف.

> ملاحظة على بيانات 2026-11-01: السهم **BCD** مسجّل بآخر سعر 42.000 بينما أعلى/أدنى سعر تنفيذ 41.000 — يُرجى التأكد هل لم يستوفِ التداول شرط تغيير سعر الإغلاق (فيبقى 42) أم أن آخر سعر يجب أن يكون 41.000 (تغير −2.38%).
