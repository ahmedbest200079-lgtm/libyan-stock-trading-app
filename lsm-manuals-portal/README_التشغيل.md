# منظومة أدلة الإجراءات الداخلية — شركة سوق المال الليبي

بوابة داخلية لعرض أدلة الإجراءات على الموظفين، بحسابات دخول فردية،
وإقرار بالاطلاع لكل دليل، ولوحة متابعة للمدير العام، ولوحة إدارة للمستخدمين.

## المتطلبات
- Python 3.9 فأحدث (على خادم داخلي أو جهاز مكتبي ضمن شبكة السوق).

## التشغيل لأول مرة
```
pip install -r requirements.txt
python app.py
```
ثم من أي متصفح داخل الشبكة: `http://<عنوان-الخادم>:8000`

- حساب المدير الافتراضي: **admin / Admin@2026** — المنظومة تُلزمه بتغيير كلمة المرور عند أول دخول
  (ولا يمكنه فتح أي صفحة أخرى قبل ذلك).
- قاعدة البيانات `data.db` تُنشأ تلقائياً بجانب `app.py` أو في المجلد المحدد بـ `LSM_DATA_DIR`
  (انسخها دورياً كنسخة احتياطية). قواعد بيانات النسخة السابقة تُرحَّل تلقائياً دون فقد بيانات.
- يُشغَّل الخادم عبر **waitress** (خادم إنتاجي متعدد المسارات) إن كان مثبتاً، وإلا خادم Flask التطويري.
- فقدان كلمة مرور المدير: `flask --app app reset-admin` يطبع كلمة مؤقتة جديدة لحساب admin.

## إنشاء حسابات الموظفين
من «إدارة المستخدمين»:
- إضافة فردية، أو استيراد جماعي بملف CSV (نموذج جاهز: `users_sample.csv`).
- إن تُركت كلمة المرور فارغة تُولَّد كلمة مؤقتة وتظهر للمدير مرة واحدة،
  ويُلزَم الموظف بتغييرها عند أول دخول.

## محتوى الأدلة
المحتوى ملفات HTML داخل `content/` يحددها `content/manifest.json`.
لإضافة دليل جديد أو تحديث إصدار:
1. حوّل ملف Word إلى HTML:  `pandoc الدليل.docx -t html -o content/<slug>.html`
2. (اختياري) شغّل `python postprocess.py content/<slug>.html` لترقية العناوين وبناء الفهرس الجانبي.
3. حدّث السطر المقابل في `manifest.json` (العنوان، الإصدار، `"status":"متاح"`).
رفع رقم الإصدار يعيد طلب الإقرار بالاطلاع من الجميع تلقائياً.

## متغيرات البيئة (اختيارية)
| المتغير | الوظيفة |
|---|---|
| `LSM_DATA_DIR` | مجلد قاعدة البيانات والمفتاح السري |
| `LSM_HOST` / `LSM_PORT` | عنوان ومنفذ الاستماع (الافتراضي `0.0.0.0:8000`) |
| `LSM_HTTPS=1` | عند التشغيل خلف وكيل HTTPS — يجعل ملف تعريف الجلسة آمناً (Secure) |
| `LSM_SECRET_KEY` | مفتاح الجلسات (وإلا يُولَّد ويُحفظ في `.secret_key` بصلاحية 600) |

## الميزات
- عارض أدلة بفهرس جانبي تلقائي قابل للتصفية، يُبرز القسم الحالي، مع شريط تقدّم القراءة وطباعة نظيفة.
- بحث عربي ذكي لا يتأثر بالتشكيل والهمزات والتاء المربوطة، مع إبراز العبارة في النتائج وداخل الدليل.
- إقرار بالاطلاع مرتبط بإصدار الدليل: يُفعَّل بعد بلوغ نهاية الدليل، ويتطلب تأكيداً صريحاً،
  ويُسجَّل معه الوقت وعنوان IP.
- تقارير CSV: الإقرارات (مع بيان ما إذا كان الإصدار نافذاً)، وغير المُقَرّ بها لكل موظف ودليل، وسجل التدقيق.
- لوحة المدير العام: نسبة الإنجاز الموزونة، ونسب كل دليل وإدارة على الإصدار النافذ، والمتأخرون،
  ومؤشرات أمنية (محاولات فاشلة، حسابات مقفلة، موظفون لم يدخلوا قط).
- إدارة المستخدمين: إضافة وتعديل (الاسم/الإدارة/الدور) وتهيئة وإيقاف وإلغاء قفل، وبحث، واستيراد CSV
  يعرض كلمات المرور المولّدة مرة واحدة.
- سجل تدقيق شامل (دخول ناجح وفاشل، وقفل، وإجراءات إدارية، وتصدير) مع عنوان IP.

## الضوابط الأمنية المطبّقة
- حماية من تزوير الطلبات (CSRF) على جميع النماذج، والخروج عبر POST.
- قفل الحساب 15 دقيقة بعد 5 محاولات دخول خاطئة.
- سياسة كلمات مرور (8 أحرف فأكثر، أحرف وأرقام، لا تتضمن اسم المستخدم، تأكيد إلزامي).
- إنهاء جلسة الحساب الموقوف فوراً، وتطبيق تغيير الدور مباشرة، ومنع إيقاف/تنزيل آخر مدير نشط.
- منع إعادة التوجيه الخارجي بعد الدخول، وترويسات أمان (CSP، منع التأطير، nosniff)،
  وعدم تخزين الصفحات المحمية في ذاكرة المتصفح، ومدة جلسة 8 ساعات.
- منع حقن الصيغ في ملفات CSV المصدّرة، وحد أقصى 2 ميجابايت للملفات المرفوعة.
- ملاحظة: ملفات `content/*.html` تُعرض كما هي، فلا تُدرج فيها إلا ملفات محوّلة من مصدر معتمد.

## ملاحظات أمنية للتشغيل المؤسسي
- شغّل المنظومة داخل الشبكة المحلية فقط، ويفضَّل خلف خادم وكيل بشهادة HTTPS داخلية.
- للتشغيل الدائم على ويندوز: أنشئ مهمة مجدولة تنفّذ `python app.py` عند الإقلاع،
  أو على لينكس: خدمة systemd. لتعدد المستخدمين الكثيف يمكن التشغيل عبر
  `waitress-serve --port=8000 app:app` بعد `pip install waitress`.
