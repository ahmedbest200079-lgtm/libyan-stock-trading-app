# libyan-stock-trading-app
تطبيق تداول الأسهم الليبي المتقدم — محاكاة افتراضية للاستثمار في سوق المال الليبي مع الامتثال الشرعي

> جميع الشركات والأسعار في التطبيق **افتراضية** لأغراض التدريب والمحاكاة، وليست بيانات حقيقية أو توصية استثمارية.

## الميزات
- **شاشة السوق**: أسعار تتحرك كل 3 ثوانٍ ضمن نطاق سعري يومي قابل للتعديل (افتراضياً ±10%)، مع إمكانية الإيقاف.
- **التداول بسعر السوق**: شراء وبيع مع حساب العمولة (0.15% بحد أدنى 1 د.ل، قابلة للتعديل) ومعاينة قبل التنفيذ.
- **المحفظة**: متوسط التكلفة (شامل العمولة)، الأرباح والخسائر المحققة وغير المحققة، والعائد الكلي على رصيد 100,000 د.ل الافتراضي.
- **الفحص الشرعي** وفق معيار AAOIFI رقم 21:
  - النشاط الأساسي مباح
  - القروض الربوية ÷ القيمة السوقية < 30%
  - الودائع الربوية ÷ القيمة السوقية < 30%
  - الإيراد غير المباح ÷ إجمالي الإيرادات < 5%
  - حساب **مبلغ التطهير** لكل سهم ولكامل المحفظة
  - وضعان: «تنبيه فقط» أو «منع شراء» الأسهم غير المتوافقة
- **سجل الأوامر** وحفظ تلقائي في المتصفح.

## التشغيل
التطبيق HTML/JavaScript بدون أي مكتبات خارجية. يحتاج خادماً محلياً بسيطاً (بسبب ES Modules):

```bash
npm start            # أو: python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## الاختبارات
```bash
npm test
```

## البنية
| الملف | الوصف |
|---|---|
| `js/engine.js` | منطق المحاكاة (فحص شرعي، تنفيذ أوامر، تقييم، حركة أسعار) — دوال نقية قابلة للاختبار |
| `js/data.js` | بيانات الشركات التجريبية — استبدلها ببيانات سوق ليبيا للأوراق المالية بنفس البنية |
| `js/app.js` | واجهة المستخدم |
| `tests/engine.test.js` | اختبارات المحرك |
